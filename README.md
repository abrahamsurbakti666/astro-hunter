# Astro Hunter (Modifikasi Star Catcher)

Tugas Praktik Publikasi Web Browser Game - Pertemuan 7

## Deskripsi Permainan
Game arcade berbasis web HTML5 di mana pemain mengendalikan kapal untuk mengumpulkan bintang sebanyak mungkin sebelum waktu habis dan menghindari meteor yang berjatuhan.

## Kontrol Permainan
- Panah Kiri / Tombol A: Bergerak ke kiri
- Panah Kanan / Tombol D: Bergerak ke kanan
- Tombol Layar: Sentuh tombol Kiri / Kanan pada layar perangkat sentuh
- Enter: Memulai ulang permainan

## Rincian Modifikasi
1. Perubahan Judul: Mengubah nama game dari "Star Catcher" menjadi "Astro Hunter".
2. Tampilan: Memperbarui palet warna latar belakang antarmuka utama pada file style.css.
3. Mekanik Permainan: Mengubah durasi timer pertandingan dari 60 detik menjadi 45 detik serta meningkatkan kecepatan gerak pemain pada game.js.
